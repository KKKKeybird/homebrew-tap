# Homebrew Tap

Personal Homebrew tap for packages maintained by KeyBird.

## Moonlight V+

Moonlight V+ is an enhanced Moonlight client maintained at
[`qiin2333/moonlight-qt`](https://github.com/qiin2333/moonlight-qt).

```sh
brew tap KKKKeybird/tap
brew install --cask moonlight-vplus
```

Upgrade it with:

```sh
brew update
brew upgrade --cask moonlight-vplus
```

The cask is checked against the latest upstream GitHub Release every six hours.
